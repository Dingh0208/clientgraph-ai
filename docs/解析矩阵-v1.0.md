## 3. 未覆盖/缺口

- 压缩包只登记不解压；压缩包内子文件无法进入解析。

- 图片/PDF OCR 不处理手写体、复杂版式与多栏阅读顺序。
- 未覆盖密码保护的 Office/PDF/压缩包。
