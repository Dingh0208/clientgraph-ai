# PRD 摘要：需求澄清助手 v0.4.0

> 日期：2026-11-08
> 来源：`PRD-客户信息聚合工作台-v1.0.md` 附录 A
> 关系：v1.0 需求基线不变，本摘要记录 v0.4.0 的实现范围与验收口径

## 1. 目标

面向单人多项目软件公司经营者，把客户资料转成可追溯的澄清工作单：选材 → 分批分析 → 带证据的问题 → 甲方回答 → 人工追问 → 回写需求/项目 → 对外输出。重点不是生成更多问题，而是每个问题、回答和字段变更都能回到原文证据，并在人工确认后才写业务记录。

## 2. 用户与场景

| 用户 | 场景 |
|---|---|
| 老板 / 售前负责人 | 选客户与资料、确认发送范围、向甲方提问并跟进 |
| 老板本人 | 判断回答是否充分、决定是否追问、确认回写预览 |
| 交付 / 方案人员 | 查看已完成澄清单，按客户/项目导出对外版 |

## 3. 本期范围

- 选材：客户/项目/未归档/跨项目；不可读资料阻止发送；发送前确认范围。
- 分批：按模型输入上限拆批；取消、失败重试、追加资料只分析新增。
- 问题：10 个行业维度、相关性过滤、单事项；三档优先级；每题附原文、来源、时间、理由、事实/推断/未知、低置信度提示；冲突保留双方证据且不自动裁定。
- 状态：待问/已问/已回答/不适用；已问未答不算完成；多次回答追加时间快照。
- 追问：只有老板点击才生成，不自动追问。
- 回写：先选目标客户/项目；只预填明确支持的字段；新需求默认待确认；P0/P1/P2 独立判断；人工确认后写入并保留版本与操作快照。
- 工作单：六态生命周期；归档默认隐藏可恢复；复制草稿；删除工作单保留原始资料。
- 导出：按客户/项目复制文本，导出 Word/PDF；对外版隐藏内部理由与证据。

## 4. 非目标

- 不自动替甲方回答，不自动裁定冲突；
- 不把问题优先级当作需求优先级；
- 未人工确认不写需求/项目；
- 不删除原始资料，不跨客户合并；
- 不把模型失败伪装成完成。

## 5. 验收口径

| 指标 | 目标 |
|---|---|
| 问题可追溯 | 100% 问题带证据或明确标记未知 |
| 追问可控 | 0 次自动追问 |
| 回写安全 | 100% 写入需确认，未确认写入 0 次 |
| 结论口径 | 已问未答不计完成 |
| 失败可恢复 | 失败批次可重试，失败案例保留率 100% |
| 对外脱敏 | 对外文本/Word/PDF 不含提问理由与证据 |
