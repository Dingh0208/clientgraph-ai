# 性能记录 v0.5.0

> 日期：2026-11-08
> 环境：Windows 单机，localhost:8140，Python 3.12
> 证据：`evidence/deployment-v0.5.0.json`、`evidence/deployment-v0.5.0-restored.json`

## 1. 方法

- 部署 v0.5.0 后，用 Python `urllib` 连续请求 `/api/health` 30 次，取 p50/p95/max；
- 用 Playwright Chromium 156 实际加载首页，记录 `domcontentloaded` 时间与正文；
- `/api/diagnostics` 计时一次；
- 统计静态文件大小（部署目录）；
- 不启用真实模型/ASR/OCR，不代表外部服务时延。
