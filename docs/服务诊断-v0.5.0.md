| 接口 | 用途 |

| `/api/health` | 服务进程存活、版本、build_id、是否需要登录 |
| `/api/diagnostics` | Sidecar、微信、ffmpeg、OCR、ASR 的真实检测状态 |
| `/api/components/{id}/log` | 最近日志尾部，不返回密钥 |

## 4. 启动策略

- 组件最多尝试 2 次，冷却 3 秒；
- 端口冲突不重复拉起；
- 启动失败保留具体错误码与日志尾部，不返回“服务不可用，请重试”；
- 应用退出不伪造通知或发送记录。

## 5. 日志与安全

- 日志位于 `ops-logs/`（本地，不随发布物提交）；
- 不记录密码、会话令牌、模型密钥；
- `/api/diagnostics` 与组件日志受 Web 登录保护（局域网/公网模式）；
- 诊断服务仅绑定本机时无鉴权，不得暴露公网。

## 6. 限制

- Sidecar/微信引擎未随仓库交付；
- OCR/ASR 未安装时显示真实缺失，不提供假结果；
- 未做系统级崩溃、僵尸进程、磁盘写满的故障注入；
- 诊断结果是一次采样，不是持续监控。
