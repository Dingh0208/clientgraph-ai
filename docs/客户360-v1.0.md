## 2. 时间线规则

- 以 `occurredAt`（真实发生时间，ISO-8601，+08:00）倒序排列；
- 只有日期没有精确时间的，`occurredAt=null`，显示“时间未知”并排在最后；
- 时间缺失时同时显示资料日期（如“资料日期 2026-09-18，无精确时间”），不伪造时间；
- 同一时间按资料 ID 稳定排序；
- 每条证据带来源类型、项目、原文摘要与 locator，点击可打开现有证据抽屉。

## 3. 不串线规则

客户 360 只按 `material.customerId` 过滤，不按文本中出现的公司/人名推断归属：

- 青岚（c1）的客户 360 不出现恒晟（c2）的 M10 与 p3；
- 青岚聊天 M11 虽然正文提到恒晟，但归属仍是 c1，保留在 c1 时间线；
- 青岚两个项目 p1/p2 分开显示，p2 的 M13 不进入 p1 的资料数；
- 恒晟客户 360 只有 p3 与 M10，不出现任何 c1 资料。

## 5. 限制

- 原型数据是内置虚构语料，时间字段为演示手工设定，不是从原始文件自动解析。
- 客户/项目归属依赖 `customerId/projectId`；没有自动实体解析。
- 风险来自预置 GAPS，不是自动检测。
- 下一步动作来自预置 NEXT_ACTIONS，未与待办系统联动。
- 时间缺失只标 M12 一条；真实数据需要解析器提供 `occurredAt` 与精度。
- 时间线暂不含需求/风险事件，只含来源资料；需求与风险在独立卡片展示。
- 客户 360 为只读视图，修改仍走待归档/需求回写流程。
