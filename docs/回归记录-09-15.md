## 3. 失败案例清单

| 错误码 | 场景 | 行为 |
|---|---|---|
| `E_EMPTY_AUDIO` | 0 字节音频 | 失败，原件保留 |
| `E_SEGMENT_FAILED` | 切片注入失败 | 失败，已完成片段保留 |
| `E_ASR_TIMEOUT` | 单片段超时 | `partial`，可只重试失败片 |
| `E_VIDEO_NO_AUDIO` | 视频无音轨 | 失败，不读画面 |
| `W_OCR_NO_TEXT` | 低清图片 | 完成但 0 块，明确警告 |
| `E_OCR_FAILED` | 第 2 页 OCR 异常 | `partial`，第 1 页保留 |
| `E_FILE_CORRUPT` | 损坏 DOCX/XLSX | 失败 + 另存建议 |
| `E_LEGACY_FORMAT` | `.doc` / `.ppt` 无转换器 | 失败 + 另存建议 |
| `E_CORRUPT` | 导入 F07 损坏 PDF | 35% 失败，其他任务继续 |
| `E_PORT_CONFLICT` | 8765 被占用且健康检查失败 | 不重复拉起，提示结束冲突进程 |
| `E_NOT_CONFIGURED` | 未配置启动命令 | 不启动，提示配置或用文件导入 |
| `E_START_FAILED` | 启动进程立即退出 | 日志尾部 + 冷却 3 秒 |
| `E_COOLDOWN` | 冷却期重试 | 拒绝并提示剩余秒数 |
| `E_MAX_ATTEMPTS` | 连续失败 2 次 | 停止自动尝试，要求人工处理 |
