## 6. 人工步骤（平台/引擎不支持时）

### 6.1 Edge（Windows，与 Chromium 同内核）

1. 启动 `python -m ops.server --port 8123 --require-auth`，打开 `http://127.0.0.1:8123/` 并登录。
2. 按 A1→K1 顺序执行：错误密码、正确登录、退出、概览、搜索预算/无结果/空输入、客户与项目、客户 360、澄清全选/预览/关闭/刷新、导入开始/失败/重试/取消/重置、待归档忽略/恢复、诊断刷新/复检、设置校验/保存/测试/刷新、上传文本/上传 exe、重新登录。
3. 打开 DevTools Console，确认无 `pageerror`；Network 过滤 4xx，确认仅上述预期项。
4. 调整窗口到 1024×768、1280×800、390×844，记录横向滚动宽度。

### 6.2 Firefox

1. 安装 Firefox 后打开同一地址；登录。
2. 重点复核：搜索抽屉、澄清复选框、导入进度、设置保存、文件上传。
3. 记录与 Chromium 的差异（下载、Blob、剪贴板、文件选择器）。

### 6.3 Safari（macOS）

1. 用 Safari 打开同一地址，登录。
2. 复核 390×844 布局、文件上传、设置保存、退出/重新登录。
3. 记录 Safari 对 `fetch`/`AbortController`/下载行为的差异。

### 6.4 无 Web 页面的模块

- 需求演化：运行 `python scripts/verify_requirement_history.py`，对照 `evidence/requirement-history-2026-11-06.json`。
- 待办：运行 `python scripts/verify_tasks.py`，对照 `evidence/tasks-2026-11-06.json`。
