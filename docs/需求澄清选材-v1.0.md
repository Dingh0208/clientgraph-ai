## 1. 四种视图

| 视图 | 过滤 | 说明 |
|---|---|---|
| 客户 | 按客户 ID | 列出该客户所有项目的资料 |
| 项目 | 按项目 ID | 只列该项目资料 |
| 未归档 | 客户和项目均为空 | 支持未归属资料 |
| 跨项目 | 全部资料 | 可混选不同客户/项目 |

行内展示：资料名称、类型、客户、项目、可读性、片段数。客户/项目为空显示“未归属”。

## 2. 勾选与全选

- 每行独立复选框；
- “全选当前筛选”只选中当前视图/筛选下**可读**的资料；
- 已选集合跨视图保留，支持跨项目混选；
- 不可读资料复选框禁用，不计入全选；
- 计数显示：`已选 / 当前筛选 / 不可读`。

## 3. 发送前确认

点击“确认选择并预览”打开抽屉，逐条列出：

- 资料名称、资料 ID、类型；
- 客户 / 项目（为空显示“未归属”）；
- 可读性；
- 片段数（材料数量）；
- 默认文本模型 `qwen3.8-flash（默认）`。

顶部汇总：总份数、可读份数、未归属份数、默认模型。

必须勾选“我已核对资料名称、归属、可读性和默认文本模型”，确认按钮才可用。存在不可读资料时拒绝保存。

## 4. 选择快照

确认后保存：

```json
{
  "id": "SNAP-…",
  "createdAt": "…",
  "scope": "customer | project | unfiled | cross",
  "filter": {"customerId": null, "projectId": null},
  "model": "qwen3.8-flash（默认）",
  "total": 12,
  "items": [
    {
      "materialId": "M01",
      "name": "微信聊天",
      "type": "chat",
      "customerId": "c1",
      "projectId": "p1",
      "readable": true,
      "blockCount": 7,
      "locator": "chat://M01",
      "model": "qwen3.8-flash（默认）"
    }
  ]
}
```

- 快照只复制名称/类型/归属/可读性/片段数/locator，不修改 `MATERIALS`；
- 快照存 localStorage，保留最近 20 份；
- 同一选择再次确认会生成新快照，不覆盖旧快照；
- “开始分析”只读取快照，原型不调用模型。

## 6. 限制

- 原型快照存 localStorage，不是后端事务；换浏览器/清缓存会丢失。
- “默认文本模型”是原型固定值，未接设置页真实模型。
- 未实现实际分析调用；“开始分析”只展示快照提示。
- 不可读状态由资料 `readable:false` 模拟，未接真实加密/损坏检测。
- 全选只作用于当前筛选的可读项；跨视图已选项不会自动清除。
- 快照只保存引用与副本字段，不保存文件二进制。
