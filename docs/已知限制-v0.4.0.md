# 已知限制 v0.4.0

> 日期：2026-11-08
> 适用：v0.4.0 需求澄清助手完整回归后的代码、文档与原型
> 前版：`docs/已知限制-v1.0.md`（解析、诊断、性能等历史限制继续有效）

## 1. 产品与架构

- 单机、单用户原型；无账号、权限、团队协作与云端同步。
- 澄清单、问题、回答、回写快照目前为**内存对象**，未接 SQLite/后端；进程退出即丢失，回归脚本每次重建演示数据。
- 澄清助手的关键操作（标记已问、记录回答、生成追问、回写确认、归档/恢复）尚未接到原型页面按钮，只有 Python API。
- 前端原型的澄清单仍以选材与演示数据为主，未与本轮工作单对象联动。
- 所有客户、项目、人名、资料均为虚构演示内容，不对应真实客户。

## 2. 规则与识别

- 问题计划为固定 10 维规则，不按行业（银行/券商/保险等）细分；行业专属问题需后续扩展。
- 问题优先级是**字段级固定规则**，不随资料顺序、置信度或冲突变化。
- 回答/回写的字段识别依赖正则：日期只认完整年月日，“月底/下周”不预填；负责人、预算、平台、范围均为常见句式，复杂表述会漏识别。
- 回写预览不支持逐字段手工修改；只预填回答明确支持的字段，其余保持原值。
- 需求 P0/P1/P2 为关键词规则，未结合历史报价、工作量与客户等级。
- 冲突检测为规则匹配，维度到问题字段的映射较粗（如 scope 统一落“本期包含”），需要精确时由调用方直接给 `field`。
- 回答是否充分不做自动判断；“基于回答生成追问”必须由老板点击，追问文本可由老板输入或使用默认问法。

## 3. 数据与流程

- 工作单六态与完成度按问题结论推导；“已问未答”始终计未完成。
- 追加资料不会自动复活已完成单，必须显式开始增量分析；未分析资料只登记，不计入批次。
- 删除工作单为软删，资料快照保留；当前没有恢复已删除工作单的界面入口。
- 归档可恢复，但归档不冻结内容，恢复后仍可追加资料。
- 多客户/多项目澄清单需在问题入单时带 `customer_id`、`project_id`，否则导出归入“未归属”。
- 同一父问题可生成多条追问，未做追问链深度限制。
- 没有撤销操作，只保留回答快照、版本与操作前后快照。

## 4. 导出

- Word 为最小 OOXML，仅标题/段落/字体与 A4 页边距，不含目录、页眉页脚、表格样式。
- PDF 依赖本机 Edge/Chrome 无头模式；未安装浏览器时返回 `E_PDF_ENGINE`，只能导出 Word。
- 一次导出只针对一个澄清单，不支持跨单合并。
- 对外版只隐藏提问理由、证据、不适用原因、置信度与内部模型参数；**不替代人工脱敏审查**，客户名称、金额等业务信息仍需使用者自行判断。
- 文本导出为纯文本，不保留 Markdown 样式。

## 5. 解析与外部能力

- ASR 默认 Mock，Qwen 未配置、未联调；真实时延、限流、费用未测。
- OCR 依赖本地 RapidOCR；`.doc`/`.ppt` 依赖 LibreOffice；压缩包/微信数据库未解析。
- 2.1 GB 视频、62 分钟音频、200 页 OCR 为界面负载模拟，不代表真实吞吐。
- 无外部模型时，批次失败路径通过本地模拟注入验证。

## 6. 安全与审计

- 本地运行目录与内存数据未加密；没有字段级权限。
- 删除、归档、回写确认记录在对象内，不是不可篡改审计日志。
- 对外导出只做内容裁剪，不生成水印、不记录导出审计。
- 仓库与证据文件已脱敏：无平台密钥、无真实客户资料、无截图；演示数据标注“虚构”。

## 7. 测试与发布

- 回归为 Windows 单机单次运行，未做多浏览器、移动端、无障碍与并发专项。
- 端到端 48 项、模块合计 200+ 项检查均通过；预期失败 7 例保留，未删除。
- 无 CI、签名安装包、自动更新与生产监控。
- v0.1.0–v0.3.0 文档保留；当前基线为 v0.4.0。

## 8. Web 单人访问与设置（第 33 轮）

- 只有一个老板密码，没有二次验证、找回密码与管理员解锁流程。
- 登录失败限速在内存中，进程重启后清零。
- 会话为无状态令牌，退出只清浏览器 Cookie，不维护服务端吊销列表；修改密码会递增 epoch 使旧令牌失效。
- 安全配置 `secure.json` 未加密，依赖目录/文件权限与操作系统账户；多人共用电脑需独立系统账户或磁盘加密。
- 公网部署必须由反向代理终止 TLS 并启用 `--secure-cookie`；本服务不内置 HTTPS。
- `live` 探测会对设置中的任意 http(s) 地址发 HEAD，属于老板主动操作；未做域名白名单。
- 设置中的默认文本/语音模型尚未接入实际 ASR/抽取流水线，当前只做服务端保存与配置检查。
- 导入偏好与通知开关已持久化，但尚未接入导入中心与提醒引擎；下一轮再联动。
- 设置页与登录页使用内联脚本，依赖同源 CSP；原型主页面仍使用 localStorage 保存演示状态（不含模型密钥）。
- Web 上传为单进程线程队列，未做多进程/并发限流；大并发只能排队。
- PDF 不做正文抽取、Office 只取文本节点；复杂版式可能丢失结构。
- ASR/OCR 未配置时阶段显示“跳过”，不生成假结果；任务为部分完成。
- 上传文件与任务 JSON 未加密，依赖本机文件权限；微信范围只校验元数据与时间戳，未验证会话归属。
- Web 跨模块回归已自动化 Chromium/Chrome/Edge；Firefox/Safari 需按《Web 跨模块回归矩阵 v1.0》人工复核。
- 390×844 主工作台横向溢出约 570 px、设置页约 22 px；移动端布局未完全适配。
- 需求演化、待办没有独立 Web 页面；Web 矩阵标记受限，结论来自后端验证。
