# 冒烟用例（可复现）

> 适用版本：v0.1.0
> 前置：`python -m http.server 8123 --directory prototype`，打开 `http://127.0.0.1:8123/index.html`

## S1 概览

1. 打开首页。
2. 读取 4 个指标卡：应分别为 12、2、3、5。
3. 客户列表应有 2 行；最近资料应有 6 条。

通过条件：数字一致，无空白卡片。

## S2 资料问答

1. 点击侧栏「资料问答」。
2. 输入 `预算`，回车。
3. 应出现 4 条证据，来源至少覆盖微信、通话、纪要、邮件四类中的三类。
4. 每条证据应带 `chat://` / `file://` / `doc://` / `mail://` 等定位符。

通过条件：证据数 ≥ 3，且类型 ≥ 3 类。

## S3 跨模态引用

1. 输入 `巡检项每个车间不一样`，回车。
2. 点击第一条证据。
3. 右侧抽屉应打开，显示标题、客户/项目、日期、原文与定位符。
4. 定位应为 `file://M02#14:20`。

通过条件：抽屉可见，定位符与原文匹配。

## S4 客户 / 项目

1. 点击侧栏「客户与项目」。
2. 应有 2 个客户卡片。
3. 需求清单应有 6 行。
4. 首行应为 `F1 / 设备台账与二维码 / 已确认 / P0 / M05`。

通过条件：数量与首行内容一致。

## S5 信息缺口

1. 点击侧栏「缺口与冲突」。
2. 应有 5 项。
3. 其中 3 项标记“必须先确认”，2 项标记“重要”。
4. 每项至少 2 条证据按钮，点击可打开抽屉。

通过条件：数量、等级、证据数一致。

## S6 未知问题

1. 输入 `有没有提到海外部署`，回车。
2. 应显示“未在工作台资料中找到依据”。
3. 引用数应为 0。

通过条件：未知提示出现，且无任何证据卡片。

## S7 敏感拒答

1. 输入 `陈晓岚的手机号是多少`，回车。
2. 应显示“该请求涉及个人敏感信息，原型按策略拒绝回答”。
3. 页面文本中不得出现 11 位连续数字。
4. 引用数应为 0。

通过条件：拒答提示出现，号码检查为否，引用为 0。

## 回归检查

- 控制台无 error / warning。
- 四个视图可来回切换，无报错。
- 刷新后回到初始状态（无持久化）。
