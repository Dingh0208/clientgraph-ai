# ClientGraph AI

> 版本：v0.1.0 · 2026-11-06
> 状态：本地交互原型（已通过 7 项冒烟检查）
> 形态：单文件 HTML，零依赖，浏览器直接打开

ClientGraph AI 面向单人多项目的软件公司经营者，把分散的客户资料聚合成可追溯的工作台：**资料问答、跨模态证据定位、客户/项目概览、信息缺口与冲突**。

本仓库是 v0.1.0 的**交互原型**，不是生产系统，也不包含模型调用。

---

## 1. 这个版本能做什么

| 能力 | 说明 |
|---|---|
| 资料问答 | 对内置的 12 份资料、51 个片段做本地检索，返回原文依据而不是生成结论 |
| 跨模态引用 | 聊天、通话、邮件、纪要、需求、报价、扫描件、表格、PPT 的证据统一展示，点击可看来源与定位符 |
| 客户 / 项目概览 | 客户、项目、资料、需求状态与最近沟通的关联视图 |
| 信息缺口 | 预算、决策人、设备数量、上线时间、审批范围 5 项待确认 / 冲突，按阻断程度排序 |
| 未知问题 | 检索不到时明确返回“未找到依据”，不猜测、不补写 |
| 敏感数据拒答 | 命中手机号 / 身份证 / 银行卡 / 账号等模式时拒绝回答，不返回任何号码 |

## 2. 快速开始

```bash
# 方式一：直接打开
prototype/index.html

# 方式二：本地静态服务（推荐，便于复现）
python -m http.server 8123 --directory prototype
# 浏览器访问 http://127.0.0.1:8123/index.html
```

无需安装依赖，无构建步骤，无网络请求。

## 3. 演示脚本

1. 打开「资料问答」，问 **预算**：返回 4 条依据，覆盖微信、通话、纪要、邮件。
2. 点击任意证据：右侧抽屉展示来源、日期、原文摘录与定位符（如 `file://M02#02:10`）。
3. 问 **巡检项每个车间不一样**：定位到通话 14:20。
4. 打开「缺口与冲突」：5 项，其中 3 项“必须先确认”，每项带双方证据。
5. 问 **有没有提到海外部署**：明确返回未知。
6. 问 **陈晓岚的手机号是多少**：拒绝回答，页面不出现任何号码。

## 5. 数据与隐私

- 内置资料全部为**虚构演示语料**，公司与人物均标注“（虚构）”，不含真实客户资料。
- 无后端、无数据库、无 localStorage 写入；刷新即恢复初始状态。
- 页面不发起任何网络请求，不加载外部字体、脚本或统计代码。
- 敏感信息拒答是**演示策略**，不是安全控制，不能替代正式的权限与脱敏系统。

## 6. 已知限制

本版本只验证交互与证据链，不包含：资料导入与解析、ASR / OCR、模型问答、需求演化、持久化、多用户与权限。完整清单见 [docs/LIMITATIONS.md](docs/LIMITATIONS.md)。
